# perfSight Examples

This directory contains example outputs generated by perfSight.

## Files

- **sample_output.json** - Example JSON output showing collected metrics
- **sample_report.html** - Example HTML report (open in browser to view)

## Viewing Examples

### HTML Report
```bash
# Open in default browser
xdg-open sample_report.html

# Or on macOS
open sample_report.html
```

### JSON Output
```bash
# Pretty print with jq
cat sample_output.json | jq .

# Or use any JSON viewer
```

## Notes

These are sample outputs demonstrating perfSight's reporting capabilities. Actual output will vary based on:
- System configuration
- Enabled metrics
- Available hardware
- Running processes
